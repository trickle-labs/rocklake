# S3 Express One Zone validation

The previous S3 Express acceptance note is withdrawn in v0.63.2. It scaled
LocalFS numbers by a guessed factor and called the result accepted without a
real AWS run. The repository has no source-identified S3 Express report, so
RockLake makes no S3 Express latency, cost, or production-tier claim.

## Current status

- S3 Express integration remains an implemented object-store path.
- No live AWS benchmark is run by routine CI.
- Remote-cloud evidence is unscheduled under v0.80.0.
- Emulator or LocalFS results cannot replace a real provider measurement.

## Required evidence before publication

A future report must include the exact RockLake source revision, AWS region and
availability zone, instance and storage configuration, dependency versions,
workload shape, raw measurements, correctness result, request and byte counts,
and the comparison baseline. The report must be generated by the candidate
checkout and linked from the claim it supports.

The v0.63.2 local smoke gate is documented in
[`benchmarks.md`](benchmarks.md). It does not exercise S3 Express.
