[ROADMAP.md](https://github.com/trickle-labs/rocklake/blob/main/ROADMAP.md).

permanent release gates. Detailed implementation work lives in
[`plans/`](https://github.com/trickle-labs/rocklake/tree/main/plans). The
v0.51.0 evidence is in the
[assessment](https://github.com/trickle-labs/rocklake/blob/main/docs/assessments/v0.51.md),
and the multi-catalog decision is in the
[catalog routing ADR](https://github.com/trickle-labs/rocklake/blob/main/docs/adr/catalog-routing.md).
Historical release notes remain in
[CHANGELOG.md](https://github.com/trickle-labs/rocklake/blob/main/CHANGELOG.md).
