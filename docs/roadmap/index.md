# Roadmap

RockLake's live roadmap is maintained in the repository root:
[ROADMAP.md](https://github.com/trickle-labs/rocklake/blob/main/ROADMAP.md).

It records the current release, Now/Next/Later priorities, non-goals, and
acceptance criteria. Historical release notes are kept in
[CHANGELOG.md](https://github.com/trickle-labs/rocklake/blob/main/CHANGELOG.md).
