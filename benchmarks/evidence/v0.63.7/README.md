# v0.63.7 local release evidence

This directory contains the candidate-specific evidence contract for the
v0.63.7 release. Reports are generated by the exact candidate SHA and retain
one JSON result per operation and repetition. Generated reports are machine
specific and are not committed as universal performance claims.

The required local profile uses 10,000 and 100,000 visible data-file records.
Optional million-file, MinIO, and emulator runs are published only when the
machine can complete them; omitted optional runs reduce the documented
envelope.

```bash
cargo run --release -p rocklake-evidence -- run \
  --backend localfs \
  --path benchmarks/evidence/v0.63.7/localfs \
  --sizes 10000,100000 \
  --repetitions 3 \
  --output benchmarks/evidence/v0.63.7/localfs.json \
  --events benchmarks/evidence/v0.63.7/localfs.jsonl
python3 scripts/validate_evidence.py \
  benchmarks/evidence/v0.63.7/localfs.json \
  --release v0.63.7 \
  --repetitions 3
```

The runner fails on digest mismatches, records exact object-store transfer
ranges, streams export measurement, and records first-row, completion, RSS,
close, and object-store counters for every raw sample.
