# v0.53.0 plan: request lifecycle ownership consolidation

## Implemented in this release

- `ConnectionContext` owns connection identity, session state, startup identity,
  protocol state, transaction status, cancellation, and connection activity.
- `RequestContext` owns request identity, operation class, timing, cancellation,
  tracing, terminal state, admission timing, and response completion.
- `AdmissionPermit` makes connection, scan, administrative, and response-buffer
  leases explicit and non-cloneable.
- `ResponseObserver` records rows, bytes, first-row timing, terminal state, and
  request completion exactly once.
- Simple query, extended query, COPY input, and COPY output share the request
  lifecycle and cancellation path.
