# v0.52.0 plan: reproducible LocalFS and MinIO scale evidence

## Delivered in this release

- `tools/rocklake-evidence` is an internal workspace binary.
- `run` prepares deterministic datasets and launches a fresh child process for
  every measurement.
- Reports include a versioned JSON document and JSON Lines event stream under
  `benchmarks/evidence/v0.52.0/`.
- Page, stream, and materialized data-file reads share a deterministic digest.
- The report records machine metadata, latency phases, RSS, CPU time, and
  object-store operation/byte counters.
- `scripts/summarize_evidence.py` renders a compact review table.

## Certification command

```bash
cargo run --release -p rocklake-evidence -- run \
  --backend localfs \
  --path benchmarks/evidence/v0.52.0/localfs \
  --sizes 10000,100000,1000000 \
  --output benchmarks/evidence/v0.52.0/localfs.json
```

Run the same matrix against MinIO with the endpoint and AWS credentials
described in [`evidence-v0.52.0.md`](../docs/performance/evidence-v0.52.0.md).

## Remaining certification gates

The runner is the implementation baseline. A release claim still requires
dedicated LocalFS and MinIO runs, repeated cold scenarios, failure injection,
consumer cancellation checks, recovery verification, and a committed review
of the bounded-memory budgets. Those are environment-dependent evidence work,
not code changes that can be truthfully completed on a developer laptop.
