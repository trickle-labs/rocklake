# v0.57.0 plan: writer ownership, failover, and multi-node routing

## Delivered

- Added expiring node leases with endpoint and health state to the managed
  registry, separate from durable catalog identity.
- Added generation-checked writer promotion. A promotion creates an
  `Acquiring` assignment; the node must acquire the catalog writer epoch before
  activating it as `Active`.
- Added assignment fencing records, epoch-backed writer readiness, and router
  checks for read-only routes and stale route generations.
- Added CLI controls for node registration, lease renewal, promotion, and
  activation.
- Kept existing read-only replicas on `open_without_epoch`, so replicas never
  contend on the writer epoch.

## Verification

```bash
cargo fmt --all -- --check
cargo test -p rocklake-router
cargo test -p rocklake-pgwire --lib
cargo test --workspace
```

Automatic lease-based failover, remote connection proxying, session drain
deadlines, TLS/mTLS between nodes, and transaction migration remain deferred.
They require fault-injection and mixed-workload evidence before becoming safe
defaults.
