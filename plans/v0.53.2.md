# v0.53.2 plan: bounded and resumable administrative jobs

## Delivered in this release

- Added a versioned job ledger under the separate TAG_SYSTEM | jobs: namespace.
- Added typed job IDs, operation kinds, lifecycle states, progress counters,
  checkpoints, terminal errors, and resource classes.
- Added idempotent creation, explicit resume, cancellation requests, safe
  cancellation acknowledgement, and durable state transitions.
- Added job conflict rules and in-process admission pools for interactive,
  online administrative, and offline-exclusive work.
- Added the rocklake catalog jobs list|status|cancel|resume commands.
- Routed long-running catalog commands through job creation and completion,
  retaining the existing explicit plan/apply safety model.
- Changed backup creation and inspection to use bounded streaming I/O.

## Verification

~~~bash
cargo fmt --all -- --check
cargo test -p rocklake-catalog jobs::tests --lib
cargo test -p rocklake-catalog backup::tests --lib
cargo test -p rocklake-pgwire --test v0514_operator_ergonomics_tests
~~~

Jobs remain explicit: abandoned destructive work is never resumed
automatically. An operator must inspect the checkpoint and invoke jobs resume
before retrying it.
