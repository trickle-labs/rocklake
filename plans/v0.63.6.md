# v0.63.6 — Honest operator output

## Scope

Make cache and capacity output distinguish measurements, operator inputs,
projections, and estimates.

## Implementation

- Report cache activity as unknown when the inspection command has no SlateDB
  cache metrics source.
- Keep the working-set calculation as an explicitly labeled estimate.
- Count snapshot rows instead of repeating the latest snapshot ID.
- Label capacity inputs, monthly projections, and historical profile ceilings.
- Remove cache-size recommendations from paths that do not configure SlateDB.
- Advance the public release manifest and operator documentation to v0.63.6.
