# v0.54.0 plan: static multi-catalog router

## Delivered in this release

- Added the internal `rocklake-router` crate with validated catalog IDs,
  aliases, locations, modes, limits, and descriptors.
- Added strict static TOML routing with immutable route-table reloads,
  traversal and credential rejection, and catalog/data prefix isolation.
- Added bounded, on-demand, single-flight catalog handle caching with safe idle
  eviction.
- Routed PG-wire startup database names to independent catalog handles and
  preserved stable catalog identity across alias reloads.
- Added `rocklake catalogs validate|list|status` with redacted location output.

## Verification

```bash
cargo fmt --all -- --check
cargo test -p rocklake-router
cargo test -p rocklake-pgwire --test v0514_operator_ergonomics_tests
```

The router remains Preview. Dynamic catalog lifecycle, authorization, quotas,
and cross-catalog operations remain out of scope for v0.54.0.
