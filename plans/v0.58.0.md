# v0.58.0 plan: disaster recovery, backup sets, and maintenance automation

## Delivered

- Added versioned catalog backup manifests with catalog format, retention,
  checkpoint, job-policy, encryption-key, and referenced-data metadata.
- Added optional bounded data-file inventory and HEAD verification without
  copying referenced data files.
- Added full-service and selected-catalog managed backup sets tied to a
  registry generation, with checksum validation for every child artifact.
- Added restore planning with explicit overwrite tokens; restored catalogs are
  verified before being published as read-only routes under new prefixes.
- Added durable maintenance policies, UTC windows, blackout periods, bounded
  due-work claims, and job-ledger submission.
- Added a stable machine-readable recovery-report schema for measured RPO/RTO
  drill results.

## Verification

```bash
cargo fmt --all -- --check
cargo test -p rocklake-catalog maintenance
cargo test -p rocklake-router backup_set
cargo test --workspace
```

Referenced data bytes remain outside metadata backups. Automatic cross-region
replication and scheduled physical excision remain deferred.
