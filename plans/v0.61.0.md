# v0.61.0 plan: evidence-driven performance, cost, and capacity

## Delivered

- Added `rocklake capacity report` with catalog counts, snapshot history,
  request and byte projections, cache budgets, configured limits, and bounded
  small/medium/large evidence profiles.
- Added dated JSON pricing inputs. Currency estimates are optional and keep
  request fees separate from measured byte rates and storage estimates.
- Added release documentation and certification coverage for the capacity
  contract without changing catalog storage formats or snapshot semantics.

## Verification

```bash
cargo fmt --all -- --check
cargo test -p rocklake-catalog capacity
cargo test --workspace
mkdocs build --strict
python scripts/check_benchmark_regression.py benchmarks/baseline.json
```

Snapshot-bound prefetch/coalescing, a SlateDB-owned fair cache,
noisy-neighbor benchmarks, and real-cloud scale certification remain deferred
until their bottlenecks and environments are measured.
