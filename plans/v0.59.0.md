# v0.59.0 plan: security, secret lifecycle, audit, and release governance

## Delivered

- Added versioned AES-256-GCM block envelopes carrying non-secret key IDs.
- Added active and read-only encryption keys so operators can rotate keys
  before rewriting and retiring old blocks.
- Kept v0.58 legacy encrypted blocks readable during rotation.
- Added tamper-evident hash-chain verification for catalog audit entries.
- Added bounded JSON SCRAM verifier files for the supported binary path.
- Added release ownership and current vulnerability-reporting policy metadata.

## Verification

```bash
cargo fmt --all -- --check
cargo test -p rocklake-catalog encryption
cargo test -p rocklake-pgwire --lib
cargo test --workspace
```

TLS hot reload, KMS/HSM providers, mTLS, and tamper-evident cross-service
audit export remain deferred until their operational and provider certification
paths are available.
