# v0.63.3 plan: safe readers and recovery

## Delivered

- Opened production read-only catalog paths with SlateDB `DbReader` while
  preserving encryption, snapshot selection, refresh, retention, and close.
- Routed the synchronous Rust client and C FFI read-only entry points through
  the independent reader path.
- Made backup publication staged and non-overwriting; inventories include data
  and delete files with canonical paths, size checks, and classified object-store
  failures.
- Cross-checked backup manifests with export headers and collected encryption
  key IDs without the old 100,000-reference cap.
- Validated retention pins, protected cleanup from live references, propagated
  retention corruption, and bounded transaction-conflict retries.
