# v0.64.0 — Quality baseline

## Delivered

- Promoted the completed v0.63.2 through v0.63.7 repair and certification work
  to the current release baseline.
- Advanced current workspace, binding, compatibility, support, deployment, and
  operator metadata to v0.64.0 without changing persisted catalog formats or
  the stable public surface.
- Kept the v0.63.7 LocalFS evidence profile as the measured release evidence
  contract and retained its raw-report validation rules.

## Evidence boundary

The release certification workflow checks the required local correctness,
recovery, isolation, compatibility, documentation, and artifact paths. Local
and emulator checks do not certify AWS S3, GCS, Azure, multi-node field
operation, or universal cloud scale.

Remote-cloud evidence, multi-node field testing, and v1.0 release candidates
remain unscheduled.

## Verification

```bash
cargo fmt --all -- --check
cargo test -p rocklake-evidence
cargo test --workspace
python3 scripts/validate_compatibility_manifest.py
mkdocs build --strict
```

The tag-triggered release workflow builds and verifies the v0.64.0 artifacts
after release certification passes.
