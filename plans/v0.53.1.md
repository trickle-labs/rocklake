# v0.53.1 plan: unified bounded metadata streaming

## Delivered in this release

- `CatalogRowStream` carries snapshot, operation class, ordering, optional row
  estimate, schema, and a fallible encoded row stream.
- `encode_metadata_row` is the schema-registry-driven encoder used by the
  storage-backed data-file, delete-file, and file-column-statistics streams.
- Storage errors and encoding errors remain stream errors, so a partial result
  cannot become a successful response.
- Cancellation is checked while waiting for storage rows and the effective
  response row window is bounded by the configured stream queue and row limits.
