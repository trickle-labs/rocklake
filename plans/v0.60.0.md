# v0.60.0 plan: compatibility, migration, upgrade, and downgrade safety

## Delivered

- Added typed version domains for DuckLake catalog, RockLake storage, registry,
  catalog backup, backup set, job ledger, audit, public JSON, and evidence.
- Added all current version domains plus read/write compatibility policy to
  `rocklake status --output json` and `rocklake --version --output json`.
- Added a typed catalog migration registry. v0.60.0 registers the current-format
  no-op, records apply attempts as durable migration jobs, verifies before any
  future activation marker, and rejects unknown targets and downgrades before
  mutation.
- Documented the v0.59.0 → v0.60.0 direct-upgrade and mixed-version window.

## Verification

```bash
cargo fmt --all -- --check
cargo test -p rocklake-core version
cargo test -p rocklake-catalog migrate
cargo test --workspace
mkdocs build --strict
```

Format-changing migrations, DuckLake v1.1, and rolling deployments beyond the
documented window remain deferred until certified fixtures and upstream corpus
evidence exist.
